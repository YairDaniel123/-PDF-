# מציג PDF מתקדם - Advanced PDF Manager
**מציג PDF מבוסס HTML ופייתון לחיפוש קבצים וחיפוש בתוך תוכן הקבצים. קל משקל, מהיר ונוח עם ממשק ברור וקל.**


## איך זה עובד?
התוכנה סורקת את התיקיות שתבחרו, יוצרת אינדקס קטן וקל משקל (**SQLite + FTS5**) ומאפשרת:
1. **עץ תיקיות נוח** לניווט מהיר בספרייה.
2. **חיפוש טקסט מלא** בתוך תוכן כל קבצי ה-PDF בשניות.
3. **פתיחה מהירה** של קבצים בדפדפן כחלון **"אפליקציה" ייעודי** ללא ממשק דפדפן מיותר
---

## גרסה 1.4 – שדרוג המנוע והביצועים (Modular Edition)
בגרסה זו בוצע שכתוב תשתיות מקיף כדי להפוך את התוכנה ליציבה ומקצועית הרבה יותר:

* **ארכיטקטורה מודולרית:** הקוד פוצל למודולים נפרדים (**ניהול נתונים**, **מנוע אינדוקס** ו**הגדרות**). הפרדה זו מבטיחה עבודה חלקה יותר, יציבות גבוהה ואפס קריסות בעומס.
* **מנגנון סריקה חכמה (Smart Sync):** המערכת מזהה רק **קבצים חדשים** או כאלו שהשתנו מאז הסריקה האחרונה ומעדכנת רק אותם. חסכון אדיר בזמן ובמשאבי מחשב.
* **ניהול מסד נתונים מקצועי (WAL Mode):** שדרוג בסיס הנתונים מאפשר עבודה מקבילית. ניתן להמשיך **לחפש בספרייה** בזמן שהאינדוקס רץ ברקע ללא נעילות או שגיאות.
* **ניהול היסטוריה משופר:** שליטה מלאה על רשימת הקבצים האחרונים, כולל אפשרות ל**מחיקת פריטים בודדים** מהרשימה לשמירה על סדר ופרטיות.
* **ריכוז הגדרות (config.py):** כל ההגדרות, הנתיבים וערכות הנושא מרוכזים במקום אחד מסודר. קל לגבות או להעביר את ההגדרות למחשב אחר.
* **מנגנון סגירה מהודק:** שיפור משמעותי בסגירת תהליכי הרקע – ברגע שסגרתם את חלון האפליקציה, השרת וכל המשאבים **מתפנים מיידית** מהזיכרון.

## גרסה 1.3
בגרסה זו שופרה חוויית המשתמש והחיפוש:
* **תצוגת Snippets:** הצגת קטע טקסט רלוונטי מהעמוד שנמצא כבר בתוך תוצאות החיפוש.
* **תצוגת עמוד בודד:** אפשרות לצפות בעמוד מסוים מתוך הקובץ הכולל **הדגשה של מילות החיפוש**.
* **שיפור ביצועי אינדוקס:** יציבות טובה יותר בטיפול בקבצים גדולים במיוחד.

---

## גרסה 1.2
שיפורים משמעותיים בחוויית הקריאה:
* **מצב קריאה:** תמיכה במסך מלא לצפייה מקסימלית.
* **חזרה למיקום אחרון:** המערכת זוכרת היכן עצרתם בכל קובץ וחוזרת לשם אוטומטית.
* **מצב כהה (Theme):** אפשרות להחלפת הרקע לכהה והכתב ללבן (כולל **היפוך צבעים מלא** בתוך ה-PDF).
* **מועדפים:** אפשרות להוספת מסמכים למועדפים וכפתור לסינון והצגת מועדפים בלבד.
* **תיקון באג סגירה:** הוספת מנגנון המבטיח שהתוכנה תפסיק לרוץ ברקע עם סגירת החלון.
